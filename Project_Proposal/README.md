# Project Proposal Feedback

## Overall Assessment

The methodology is overall well written.

## Areas to Improve

### Defining In-Game Performance

In-game performance is subjective: there may not be an objective weighting of every individual performance metric. It would be more accurate to focus on evaluating the model's predictive accuracy rather than determining whether influences beyond performance affect the outcome.

### Stating the Hypothesis

The proposal mentions that metrics will either confirm or deny the hypothesis, but it does not explicitly state the hypothesis. Include a clear statement of the hypothesis being tested.

### Accounting for Changes Across Seasons

Normalizing scores across seasons may not be enough. The statistics people value may change over time, which may need to be considered in the modelling approach.
